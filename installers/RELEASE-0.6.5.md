# Saldonaut 0.6.5

## Highlights

- Adds the optional **Cosmic (dark)** appearance with Saldonaut's bundled orbit artwork behind the application content.
- Keeps the regular dark appearance available as a calm, image-free alternative.
- Applies and stores the selected appearance before sign-in without changing financial profiles or data.
- Shows the playful “Your wealth – astronomical” overview heading only in Cosmic mode.
- Includes complete German, English, French and Italian interface translations and updated local help.

## Windows download

Download `Saldonaut_0.6.5_x64-setup.exe` and its SHA-256 checksum from this release.
The installer is unsigned, so Windows may display a security warning.
Create an encrypted backup before updating or using real data.
